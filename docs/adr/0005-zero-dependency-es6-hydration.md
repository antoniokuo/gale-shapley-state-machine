# 5. Zero-Dependency ES6 Data Hydration

Date: 2026-08-04

## Status

Accepted

## Context

The application must ingest and bridge pre-computed JSON datasets (Zipfian asymmetric matrices) into the Pinia execution engine. Using third-party utility libraries (e.g., Lodash, Radash) for data parsing and object iteration introduces unnecessary dependency bloat, security auditing overhead, and marginal performance degradation.

## Decision

All data hydration, object key extraction, and dictionary mapping is executed strictly utilising native ES6+ V8 engine methods (e.g., `Object.keys()`, `Set`, explicit typecasting).

## Consequences

- **Positive:** Zero impact on the JavaScript bundle size, aligning with strict enterprise payload constraints.
- **Positive:** Direct V8 engine optimisation ensures parsing overhead during the critical rendering path is imperceptible.
- **Negative:** Requires rigorous TypeScript interface definitions to satisfy compiler strict null-checks during dynamic object key iteration.

## Amendments (2026-08-07)

### Context Update

To enforce the 5 Deterministic Milestone Breakpoints protocol (ADR 0002), the application can no longer blindly pause at arbitrary loop intervals. While the Gale-Shapley algorithm execution is computationally trivial for the V8 engine, allowing the frontend client to calculate semantic milestones (e.g., detecting the exact tick a deep displacement cascade begins) at runtime violates the Separation of Concerns. It tightly couples algorithmic business logic to the rendering layer, making it impossible to guarantee that the UI intercepts exactly aligned states across both the Static and Interactive control groups without risking race conditions.

### Amended Decision

The semantic intercept coordinates are pre-computed and stored directly within the JSON seed datasets. The ES6 hydration pipeline is updated to parse and validate a new `milestoneBreakpoints` array from the JSON payloads. This array of exact string tuples (e.g., `['P1-R2', 'P6-R1', ...]`) is hydrated directly into a native ES6 `Set` during initialisation and passed to the execution engine to guarantee interceptions at the precise algorithmic states.

### Amended Consequences

- **Positive:** Total Decoupling. Offloads milestone evaluation logic from the runtime engine to the static JSON payload, rendering the Vue client as a purely deterministic, stateless view layer.
- **Positive:** Ensures 100% deterministic and synchronised breakpoint mapping across both the Static and Interactive DAG control tasks, safeguarding the crossover study's telemetry.
- **Negative:** Requires rigorous schema validation on the static JSON files to ensure the hardcoded `milestoneBreakpoints` array perfectly matches the actual state execution path generated by the Zipfian matrices.
